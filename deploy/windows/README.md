# نصب روی ویندوز سرور (کنار ربات اصلی در `C:\apps\judicial-bot`)

پوشهٔ ربات: `C:\apps\regional_value` (کد، `.env` و `data\bot.sqlite3` از قبل منتقل شده‌اند)

1. پوشهٔ `deploy\windows` را (از همین PR) داخل `C:\apps\regional_value\deploy\` کپی کنید.
2. PowerShell را **Run as Administrator** باز کنید:
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\apps\regional_value\deploy\windows\install.ps1
   ```
3. `rvbot test` ← پیام آزمایشی باید در بله برسد (ادمین باید یک بار ربات را `/start` کرده باشد).

## اسکریپت نصب چه می‌کند
- بررسی `.env` (BOT_TOKEN، ADMIN_ID، NESHAN_API_KEY) و وجود دیتابیس
- **بررسی تداخل:** توکن تکراری با `.env`های دیگر `C:\apps`، پوشهٔ اشتباه، نمونهٔ دستیِ در حال اجرا
- بررسی venv؛ اگر venv کپی‌شده روی سرور کار نکند، دوباره ساخته می‌شود (قبلی با نام `venv_old_…` می‌ماند)
- تسک `RegionalValueBot`: ناظری که با روشن شدن سرور (حتی بدون لاگین) اجرا می‌شود، ربات را ۱۰ ثانیه پس از هر قطعی دوباره بالا می‌آورد و به ادمین خبر می‌دهد
- تسک `RegionalValueBot-Watchdog`: هر ۵ دقیقه چک می‌کند ناظر و ربات زنده‌اند
- دستور `rvbot`: `status`، `logs`، `restart`، `stop`، `start`، `test`، `uninstall`

## پیام‌های ادمین
| رویداد | پیام |
|---|---|
| ریبوت سرور | 🔄 سرور ریبوت شد؛ ربات اجرا شد |
| قطعی ربات | ⚠️ با کد خروج و ۱۵ خط آخر لاگ |
| بازگشت پس از قطعی | ✅ دوباره راه‌اندازی شد |
| ناظر از کار افتاده | 🩺 پایشگر دوباره راه‌اندازی کرد / 🚨 بالا نمی‌آید |

در قطعی‌های پشت‌سرهم، ۳ پیام اول هر ساعت و بعد هر دهمین ارسال می‌شود. اگر هنگام قطعی اینترنت یا بله در دسترس نباشد، پیام در صف می‌ماند و بعداً ارسال می‌شود.

لاگ‌ها: `C:\apps\regional_value\logs` (لاگ‌های ربات ۱۴ روز نگه داشته می‌شوند).
